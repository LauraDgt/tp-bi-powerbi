# TP BI Power BI — Analyse du catalogue Netflix

## Présentation
Ce dépôt contient un TP d’introduction à la Business Intelligence réalisé dans le cadre du Master 1 Management des Systèmes d’Information à Grenoble IAE.

L’objectif du projet était de concevoir un premier tableau de bord Power BI à partir d’un jeu de données public, en construisant un schéma en étoile, en définissant des indicateurs de performance, puis en réalisant un dashboard interactif.

## Sujet du projet
J'ai travaillé sur le dataset **Netflix Movies and TV Shows**, issu de Kaggle, contenant des informations sur les contenus présents dans le catalogue Netflix.

## Objectifs du TP
- Identifier deux indicateurs de performance
- Concevoir un schéma en étoile
- Réaliser la table de correspondance entre la source et le modèle décisionnel
- Implémenter le modèle dans Power BI
- Créer un tableau de bord avec filtre fonctionnel et page drill-through

## Contenu du dépôt
